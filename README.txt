Deploy to Cloudflare Pages:
1. Go to Cloudflare Dashboard > Workers & Pages > Create application > Pages.
2. Choose "Upload assets".
3. Upload the contents of this folder, or upload the zip file.
4. After deployment, add your custom domain: codefidelity.ai.
