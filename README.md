# CodeFidelity AI Landing Page

Coming-soon landing page for [CodeFidelity AI](https://codefidelity.ai) — enterprise code intelligence for search, security, AI governance, and release awareness.

## Files

- `index.html` — main landing page
- `assets/codefidelity1.svg` — logo
- `CodeFidelityAI_Master_Knowledge_Base_v1.md` — company messaging and product knowledge base

## Local preview

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080

## Deploy to Cloudflare Pages

1. Go to Cloudflare Dashboard → Workers & Pages → Create application → Pages
2. Choose **Upload assets**
3. Upload the contents of this folder
4. Add custom domain: `codefidelity.ai`
